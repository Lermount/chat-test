Для запуска проекта потребуется Node.js версии 18 или выше.

1. Клонирование репозитория:
   git clone https://github.com/Lermount/chat-test.git
   cd chat-test

2. Установка зависимостей:
   npm install

3. Запуск в режиме разработки:
   npm run dev

Проект будет доступен по адресу http://localhost:5173.
